# Flutter + Dart Frog Project Setup

1. Use flutter sdk latest version.

2. Clone the project.

3.  Start with backend
```bash
cd backend
```
and run the dart frog project  
```bash
dart_frog dev
```  
Noted that if you are run front end with real device please define the ip and run e.g  
```bash
dart_frog dev --hostname 192.168.170.212
```

4.  Start with front end
```bash
cd frontend
```
and run the flutter front end  
```bash
flutter pub get
flutter run
```
